# AI Image Generator 🎨

## About the Project
AI Image Generator is a web-based application that transforms text prompts into creative images using AI-powered image generation. It provides a simple and user-friendly interface where users can enter prompts, choose their preferred aspect ratio, generate multiple images, preview the results, and download images easily.

## ✨ Features
- Generate images from text prompts.
- Select different image aspect ratios.
- Generate multiple images.
- Preview AI-generated images.
- Download generated images in PNG format.
- Use example prompts to get started quickly.
- Responsive and user-friendly interface.
- Error handling for failed image generation requests.

## 🛠️ Technologies Used
- HTML
- CSS
- JavaScript
- Google Gemini API
- Remix Icon
